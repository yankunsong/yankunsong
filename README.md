### 🧭 How I think

I start from the problem, not the model. A good AI solution is one that removes a painful step from someone's day — reliably, in production, with real data. Demos are easy; **systems people trust** are the job.

- **LLM applications & agents** — RAG pipelines, tool-use / agent workflows, prompt & output design, evaluation
- **AI in regulated finance** — 3+ years building on FINRA's Consolidated Audit Trail (CAT / CAIS), later on FINRA's AI team
- **End-to-end delivery** — from a one-week prototype to a deployed, maintainable product

### ⚙️ How I work

1. **Understand the workflow** before touching a model.
2. **Ship a thin slice fast** — working software in days, not months.
3. **Measure it** — evals and real users beat impressive demos.
4. **Leave it maintainable** — clean code, docs, and a handover someone else can run.
